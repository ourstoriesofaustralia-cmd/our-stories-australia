# Рассказы об Австралии — GitHub Pages

This is a dependency-free static site, ready for GitHub Pages. The PDFs remain in Google Drive, so the site itself stays fast and there is nothing large to upload.

## Publish

1. Create a new GitHub repository (for example, `our-stories-australia`).
2. Upload the contents of this folder to the repository root and commit them to `main`.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then `main` and `/(root)`, then save.
4. GitHub will provide the public `github.io` address. To retain `www.ourstoriesofaustralia.com`, point the domain's DNS to GitHub Pages and add the custom domain in the same Pages settings.

Before switching the domain, test every Google Drive link in the published copy. Each Drive file must be shared as “Anyone with the link can view.”
